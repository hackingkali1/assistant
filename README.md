Chunav Saathi – Interactive Indian Election Assistant

An interactive, multilingual web application designed to help users understand the Indian election system in a simple, structured, and engaging way.

This project combines modern UI/UX, educational content, and AI-powered chat (Gemini integration) to create a guided learning experience for anyone curious about how elections in India work.

🚀 Features
🌐 1. Complete Election Guide
Big picture overview of India's election system
Step-by-step voting process
Election timelines (announcement → results)
Government formation explained

🧠 2. Key Concepts Simplified
First Past The Post (FPTP)
Constituencies
EVM & VVPAT
Majority (272 seats)
Hung Parliament

🗳️ 3. Interactive Voting Flow
Visual step-by-step experience of how a voter votes
Real-world explanations with tips

🌍 4. Multilingual Support
Supports multiple Indian languages
Dynamic UI translation
RTL language support (like Urdu)

💬 5. AI Chat Assistant (Gemini Integrated)
Ask questions about elections, government, MPs, MLAs, etc.
Hybrid system:
Fast responses using knowledge base
AI-generated answers using Gemini


🧪 6. Quiz System
Test your understanding with interactive questions
Covers key election concepts


🎨 7. Modern UI/UX
Clean dark theme
Sidebar navigation
Animated sections and transitions
Mobile responsive design



🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
AI Integration: Gemini API


Architecture:
Modular UI sections
Knowledge Base + AI hybrid chatbot
Multilingual system
